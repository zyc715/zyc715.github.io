📌 任务二：个人博客的搭建
本文记录了使用 Hexo 框架搭建个人博客，并将其部署到 GitHub Pages 的完整流程。

一、任务背景

本次任务要求使用 Hexo 框架搭建个人博客系统， 选择合适的主题对博客进行配置， 并通过 GitHub Pages 实现博客的在线访问。

二、环境准备

在正式搭建博客前，需要准备以下开发环境：
  • 操作系统：Windows
  • Node.js（用于运行 Hexo）
  • Git（用于代码管理与部署）
  • GitHub 账号（用于博客托管）

三、Hexo 博客初始化

Step 1：安装 Hexo
npm install -g hexo-cli
Step 2：初始化博客项目
hexo init myblog cd myblog npm install
Step 3：本地启动博客
hexo s
在浏览器中访问：http://localhost:4000 若能成功访问页面，说明博客初始化完成。
