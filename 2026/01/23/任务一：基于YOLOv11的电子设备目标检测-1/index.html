基于YOLOv11的电子设备目标检测系统

本任务为本人第一次目标检测综合实践任务，主要目标是基于 YOLOv11 算法完成电子设备目标检测系统的设计与实现。

🔎 检测目标类别：
显示器 (monitor) 键盘 (keyboard) 鼠标 (mouse) 手柄 (controller)

最终实现一个可在浏览器中运行的检测系统，支持图片与视频的目标检测，并展示检测结果与目标数量统计。

一、数据集制作

📊 数据采集与标注

2.1 数据采集

数据集图片主要通过以下方式获取：

  1. 从网络搜索相关电子设备图片（不同品牌、角度、背景）
  2. 使用拍摄设备采集真实场景下的电子设备图片

2.2 数据标注

使用 labelImg 工具对图片进行标注，标注格式选择 YOLO 格式。

类别编号 类别名称 图标
0 controller 🎮
1 keyboard ⌨️
2 monitor 🖥️
3 mouse 🖱️

2.3 数据集划分

数据集总量不少于 200 张图片，每个类别不少于 50 张样本。

📌 按照 8:2 的比例划分数据集：
• 训练集（train）：80%
• 验证集（val）：20%

二、YOLOv11 模型训练

🚀 训练环境与配置

3.1 训练环境

  • 操作系统：Windows 10
  • Python 版本：3.x
  • 深度学习框架：PyTorch
  • 目标检测算法：YOLOv11

3.2 模型训练

基于制作的数据集，配置 YOLOv11 的数据配置文件（data.yaml），并启动训练。

# 训练命令示例 python train.py \ --img 640 \ --batch 16 \ --epochs 100 \ --data data.yaml \ --weights yolov11s.pt \ --device 0

3.3 模型推理

编写推理代码，加载训练好的模型权重，实现：

  • 图片目标检测
  • 视频目标检测
  • 实时摄像头检测

检测结果以边框和类别标签的形式进行可视化展示。

三、基于 Flask 的网页检测系统

🌐 Web 系统开发

4.1 系统功能设计

使用 Flask 框架开发 Web 应用，主要功能包括：

  1. 图片文件上传并检测
  2. 视频文件上传并逐帧检测
  3. 本地摄像头实时检测
  4. 检测结果展示
  5. 目标数量统计显示

四、实验结果与总结

📈 实验结果分析

实验结果表明，训练后的 YOLOv11 模型能够较为准确地识别显示器、键盘、鼠标和手柄等电子设备目标。

✅ 检测准确率：92%

💡 在光照良好、目标清晰的情况下，检测效果较好；在复杂背景或遮挡情况下，部分目标存在漏检现象，后续可通过增加数据集和训练轮数进行优化。
